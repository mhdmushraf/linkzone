# Linkzone

Sales CRM for distributors and wholesalers: find retailers in any area, send offers on WhatsApp, and turn replies into orders.

**Live:** https://crm.linkzoneglobal.com

## Features
- Lead finder with map search and bulk add
- WhatsApp inbox, orders, products and delivery routes
- Multi-team organisations with invites and roles
- Stripe subscriptions: 14-day trial, card updates, monthly/annual billing

## Tech
React, serverless backend functions, Stripe, maps and geocoding, WhatsApp
